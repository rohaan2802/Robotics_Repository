HOMOGENEOUS COORDINATES - WHY THE LAST ROW IS 0 0 1

1. Moving from 2D to 3D

2D (x-y)
- x: left / right
- y: up / down
- e.g. y = (x-2)^2 + 3 -> curve shifted 2 right and 3 up

3D (x-y-z)
- x: left / right
- y: front / back (into or out of the screen)
- z: up / down
- Translation can happen along any of the three axes.

Fixing one axis
- e.g. z = 5, x = t^2, y = 2t
- z stays at 5, so the curve is a flat x-y curve sitting at height 5.
- If only x changes (y and z fixed) -> straight line parallel to the x-axis.
- Holding one coordinate constant = working on a 2D slice of 3D space.

2. Why add 0 0 1 (or 0 0 0 1)?

Because we use homogeneous coordinates. A plain 2x2 (or 3x3) matrix can rotate and scale but cannot translate. Adding one extra coordinate lets rotation, scaling, shearing and translation all be done with a single matrix multiplication.

2D
- point (x, y) -> (x, y, 1)
- 3x3 transformation matrix:
  [ a  b  tx
    c  d  ty
    0  0  1 ]
  - a, b, c, d: rotation / scaling / shear
  - tx, ty: translation
  - last row fixed at 0 0 1

3D
- point (x, y, z) -> (x, y, z, 1)
- 4x4 transformation matrix:
  [ R(3x3) | T(3x1)
    0 0 0  |   1   ]
  - R: rotation (and scaling)
  - T: translation
  - last row fixed at 0 0 0 1

3. How to recognise a homogeneous matrix
- 2D: 3x3 with last row 0 0 1
- 3D: 4x4 with last row 0 0 0 1
- Reasons for this last row:
  - keeps matrix multiplication compatible so transforms can be chained
  - keeps points (last coordinate 1) and directions (last coordinate 0) separate
  - keeps the transformation affine

4. Why exactly 0 0 1 and not other numbers?
- The 1 lets the translation column act on the point when multiplying.
- Keeps the transform affine: straight lines stay straight and parallel lines stay parallel.
- Using e.g. 0 0 2 scales the homogeneous coordinate -> becomes a projective transformation, not affine, and the result is distorted.
- 0 0 1 leaves the extra coordinate unchanged, so the result is a clean 2D (or 3D) transformation.

Summary
- Homogeneous coordinates add a 1 to every point.
- Last row 0 0 1 (2D) / 0 0 0 1 (3D) allows translation by matrix multiplication and keeps the transform affine.
- Any other value turns it into a projective transform and distorts the result.
