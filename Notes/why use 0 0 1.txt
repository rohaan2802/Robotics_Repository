Question:
why we add 0 0 1 in last row and last column of matrix somwtimes ???

Answer:
Excellent question! The reason we sometimes add a 0 0 1 (or 0 0 0 1 in 3D) as the last row and column in a matrix is because we are using what's called homogeneous coordinates.

✅ Why do we use homogeneous coordinates?
They allow us to perform translation, rotation, scaling, and perspective transformations using matrix multiplication — even translation, which normally can't be done with just a regular 2×2 or 3×3 matrix.

🔷 In 2D Transformations (like for graphics, robotics, etc):
A regular point is: Point (x, y)
In homogeneous form, it becomes: Point (x, y, 1)

Then a 3×3 matrix can represent: rotation, scaling, translation — all in one matrix!

For example:
Transformation Matrix = 
[ a  b  tx
  c  d  ty
  0  0  1 ]
- tx, ty handle translation.
- 0 0 1 ensures this works correctly in homogeneous form.

🔷 In 3D Transformations:
A point becomes (x, y, z, 1), and we use a 4×4 matrix:
[ R(3×3) | T(3×1)
  0 0 0 | 1 ]
Where:
- R is rotation and scaling
- T is translation
- 0 0 0 1 makes the matrix work properly with 3D homogeneous coordinates

🔍 Why the 0 0 1 (or 0 0 0 1)?
Because it allows you to combine rotation, scaling, and translation into a single matrix.
It acts as a sort of "switch" or "placeholder" that ensures all transformations follow matrix multiplication rules.

🧠 Without 0 0 1, translation wouldn't work:
Regular 2×2 matrices can rotate and scale, but not translate. Homogeneous matrices solve that limitation.

Question:
how we know that homogenous matrix inolves 0 0 1 row at the blast

Answer:
Great question! Here's how you know or recognize that a matrix is a homogeneous transformation matrix — and why it involves that last row like 0 0 1 (or 0 0 0 1 in 3D):

🔷 Homogeneous Coordinates: Quick Recap
To do translation, rotation, scaling, and projection using a single matrix multiplication, we convert points like:

- 2D point (x, y) → homogeneous form: (x, y, 1)
- 3D point (x, y, z) → homogeneous form: (x, y, z, 1)

🔹 How Homogeneous Matrices Are Structured
For 2D transformations, the homogeneous matrix is 3×3:
[ a  b  tx
  c  d  ty
  0  0  1 ]
- First 2×2 part (a, b, c, d) handles rotation, scaling, shearing
- Last column (tx, ty) is translation
- Final row 0 0 1 is always fixed

For 3D transformations, the homogeneous matrix is 4×4:
[ R(3×3) | T(3×1)
  0 0 0 | 1 ]
- Top left 3×3: rotation/scaling
- Right 3×1: translation
- Last row: always 0 0 0 1

🧠 Why the last row is like that?
- Matrix Multiplication Compatibility
- Preserve point vs direction
- Ensures affine transformations

🔍 Recognize a homogeneous matrix?
- 2D homogeneous: last row is 0 0 1
- 3D homogeneous: last row is 0 0 0 1

Question:
why we use only 0 0 1 not other numbers 

Answer:
We use the row [0 0 1] in 2D homogeneous transformation matrices for a specific and very important mathematical reason: it makes the transformation affine, and allows us to perform translation, rotation, scaling, and shearing using matrix multiplication.

🔹 Why [0 0 1] specifically?
Because:
- It allows points (x, y) to be represented as (x, y, 1)
- The "1" enables translations using matrix multiplication
- It keeps the transformation affine — preserving lines, angles, and parallelism

🔸 What happens if we use [0 0 c] instead?
- If you use [0 0 2], it scales the final result — it’s like applying a projective transformation, not affine.
- Result: nonlinear distortion

🔹 Intuition:
- [0 0 1] acts like a “do nothing” to the homogeneous dimension — so you keep clean 2D transformations.
- It preserves affine structure.

✅ Summary:
We use [0 0 1] in the last row of a 2D homogeneous matrix because:
- It allows translation using matrix multiplication.
- It preserves affine nature.
- Any other value breaks this property and causes distortion.
